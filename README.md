# skala-MachineLearning

KNN·군집화·트리 앙상블 실습에서 작성한 보고서와 보고서 생성 코드입니다.

- `build_*_report.py`: DOCX 보고서 생성.
- `*_실습_보고서*.docx`, `Clustering_실습_보고서.pdf`, 본인 이름의 실습 PDF: 작성한 결과물.

보고서 생성 스크립트는 저장소 루트에서 실행합니다. `python-docx`, 군집화 스크립트에는 pandas·NumPy·SciPy·scikit-learn·matplotlib·ucimlrepo, 트리 보고서에는 Pillow가 필요합니다. 생성 결과는 스크립트 옆 DOCX에 저장됩니다.

강의 PDF와 수업 실습 노트북은 업로드하지 않습니다. 원본은 로컬에 보존합니다.
